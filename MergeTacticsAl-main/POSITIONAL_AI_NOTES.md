# Позиционные изменения

В `MergeTacticsAI` добавлен консервативный поиск одной тактической перестановки в текущем цикле расстановки. Он использует только идентифицированных союзников/противников и введённые данные HP, урона, скорости атаки, дальности и скорости движения. При пропусках данных, неизвестном противнике или неопределённом юните перестановка не предлагается. Для карты сборки допустима только целевая клетка, заданная пользователем. Одна перестановка за раунд, длительный жест и последующая проверка занятости обеих клеток уже существующим циклом приложения.

Оценка использует существующую приблизительную `CombatModel`, плюс небольшой штраф за известные зоны угроз и явно отмеченные опасные клетки. Значение уверенности показывает полноту входных данных, а не вероятность победы. Изменение выполняется только при разнице не менее 0,04, полный перенос алгоритма на нераспознанные противниковые составы не делается.

## Ограничения и проверка

- Полное распознавание названий, ролей и уровней воинов на экране отсутствует. Идентичность своих войск известна только для тех, которые бот сам учёл.
- Состав противника берётся из существующего ручного тактического контекста, автоматическое обновление противника не добавлено.
- Не добавлялась история итогов боя: приложение не распознаёт победу/поражение надёжно.
- Добавлены тесты отказа от тактики без противника и при неполных боевых данных.
- Автоматическая сборка/запуск тестов в этой среде недоступны: Java и Gradle Wrapper отсутствуют.
